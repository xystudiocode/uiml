# UIML Highlight for VSCode

This repository contains an **empty shell** VS Code extension for
[UIML](https://github.com/xystudiocode/uiml) — a special XML format for drawing
PySide6 UI interfaces.

> **Status: empty shell.**
> The extension registers itself and does nothing else yet. Syntax highlighting
> and other language features are not implemented.
